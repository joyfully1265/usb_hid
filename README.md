# usb_hid

Use this to create USB HID gadgets on raspberry pi.
Create services to start the gadgets and start [usb_loopback](https://github.com/joyfully1265/usb_loopback.git) server on startup.

# Installation

usb_loopback in /usr/bin/

usb_loopback.service in /etc/systemd/system/

usb_loopback_server.service in /etc/systemd/system/
